# 五分钟开始研究

1. 在“我的产品”打开“耆宿说 · 文化知识工作台”，不用配置模型即可开始。
2. 打开“知识图谱”。拖动旋转，点击节点，右侧查看关联，点击“查看资料原文”核对内容。选择“木构建筑解读”试试分层拆解与线框。
3. 打开“智能检索”，提问“斗拱应该从哪些方面观察？”。当前资料摘录模式会返回原文和版本引用；点引用即可回到来源。
4. 点击“保存为考证”，记录自己的判断；或点击“转为创作稿”，在编辑器里补充文字、引用和所属项目，再保存。
5. 在“研究项目”进入一个项目，创建或完成任务。刷新页面，检查自己的记录仍在。
6. 准备接入真实资料时，从“导入资料”选择 Obsidian 的 Markdown 文件或文件夹，核对新增、更新和未解析链接，再确认导入。
7. 在“空间设置”导出完整备份，保存资料和来源历史。稿件可单独导出为 Markdown。

内置专家、资料与项目都是虚拟示例。木构模型用于理解构件层次，不是具体文物复原。当前未启用真实大模型，检索与原文引用可以完整使用；模型整理是后续服务端配置能力。

在线资料按浏览器会话隔离；清除会话前请导出备份。离线单文件将资料保存在当前浏览器，与在线空间不自动同步。
