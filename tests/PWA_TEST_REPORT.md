# QISU HUB 封装验收

验证时间：2026-11-24 UTC。目标：平台托管的 `app.html` 本地应用入口。

运行命令：

```sh
QISUSHUO_URL=http://127.0.0.1:<托管端口> node tests/browser-pwa.cjs
```

脚本连接现有共享浏览器，不启动浏览器或服务器，不修改用户登录状态。只在独立标签页创建唯一命名的验收资料；结束时在事务中删除这些资料及其版本，保留其他记录。断网模拟只作用于测试标签页。

## 已通过

- `app.html` 显式进入本地资料空间，页面标题显示 QISU HUB，全流程没有 `/api` 请求。
- Manifest 的名称、独立窗口模式、启动页、作用域，以及 192/512 图标正常；真实 Service Worker 已激活。
- 断网刷新后创建并保存稿件，再次断网刷新仍可读取相同正文。
- 两窗口同时编辑相同版本：先保存的内容进入版本 2；后保存的旧版本被拒绝，未保存正文仍留在编辑器中；版本 1、2 完整保留。
- 另一窗口新增记录后，旧窗口导出的完整备份包含两窗口最新资料及版本历史，兼容 `qisushuo-backup` / schema 1。
- 工作台、知识库、专家、图谱、检索、考证、创作、项目、设置、回收站共 10 类页面在 1440、390、360 像素下均无整页横向溢出；手机“更多”导航和连续输入正常。
- 注入 IndexedDB 读取请求失败后，页面显示恢复提示，初始化写入次数为 0，原资料及版本逐项保持不变。
- 通过静态路由模拟 `/qisu-hub/` 子目录，应用、Manifest、图标和 Service Worker 注册地址均保持在子目录中。
- 未捕获到页面异常、控制台错误、HTTP 错误响应或本地模式 API 请求。

机器报告位于 `test-results/pwa-report.json`；桌面、手机、存储故障和子目录截图均位于 `test-results/pwa-*.png`。这些运行产物不进入源码仓库。

## 验证边界

- 子目录采用浏览器路由从 `dist` 读取静态资源，并记录 Service Worker 注册调用；未在模拟子目录真实安装额外 Worker，避免改变用户浏览器的作用域。真实安装与断网加载在托管根地址验证。
- 备份验证浏览器下载事件与实际生成的 JSON Blob。共享浏览器的下载流接口可能返回空流，因此不把该桥的文件传输作为产品备份完整性的依据。
- 手机验证使用浏览器视口，未替代 iPhone / Android 真机安装。iOS 的“添加到主屏幕”和 Android 的安装菜单仍需对应设备验证。
- 当前测试不验证跨设备自动同步；本地应用的数据迁移使用完整备份。
