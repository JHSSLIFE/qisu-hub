# The Living Archive — 生长的人文档案

QISU HUB V3.0 视觉系统 / V3.3 Demo 设计基线

产品定位：文化遗产与数字人文知识研究操作系统（Cultural Heritage & Digital Humanities Research OS）。核心参考：Use All Five 的 Hans Ulrich Obrist: Ways of Curating。此处为项目自身的设计规范，不是参考作品的精确复刻。

## 视觉语言

- 纯白 #FFFFFF、自然白 #F7F6F2、印刷黑 #222222、印章红 #9D2933，边线 #E2E2DF。
- 六色强调：天空蓝 #4C92C9、向日葵黄 #F7AC27、新芽绿 #BDDD45、珊瑚朱红 #F04D35、鸢尾紫 #A65BEE、湖水青 #43C9B5。色彩表示主题、关联或交互；状态颜色独立，且配合文字。
- 汇文明朝体优先，涵盖中文、英文、数字、标点；保留系统宋体回退。Demo 使用本机字体或网络字体样式表；真实字形、授权、字符覆盖和离线加载尚未验收，不随包分发字体文件。
- 开放编辑式排版：以标题、正文、年份、留白、细分隔线、真实档案素材构成页面，减少矩形色块和装饰卡片；不使用无意义的曲线或不准确的古建轮廓。示意图标明非测绘/复原图；真实文化遗产影像须具出处与授权。
- 策展时间轴使用中央年份轴、交替排列的事件与关联资料，支持编年与主题视图；手机转换为纵向轴。统一组件与数据，响应式适配，确保触控和键盘可用。
- 展示页面允许较强艺术表达；编辑、考证、权限及检索页面以效率和可读性为优先。避免厚阴影、玻璃拟态、复杂渐变及大面积彩色方块。

## 五大中心与专家空间

管理员/研究成员：工作台、知识中心、专家中心、研究中心、创作中心；全局知识助理及个人空间。专家：工作台、知识中心、知识助理、口述历史四项同级入口。登录页分成员密码和专家邀请码两种模式。

## 后续验收

检查跨端字体、低字号对比度、键盘焦点、时间轴可读性、真实档案图片授权以及离线资产缓存；通过真实设备及原有 React/FastAPI 项目回归测试后再正式上线。
