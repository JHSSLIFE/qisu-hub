# V3.3 正式项目迁移计划

本目录为独立 Demo 快照，原始四个文件（index.html、server.py、README.md、TEST-RESULTS.txt）保持逐字节一致。seed.example.json 从 index.html 内置 seed 精确导出，便于检查与迁移；运行时仍以内置 seed 为准。所有记录均标记 example:true。原仓库 main 的 React/FastAPI 后端、三维引擎、账号数据库、权限、PWA 与数据不作覆盖。

1. 将视觉 token、导航、组件与时间轴逐步迁入原 src/theme.css 与 React 页面。保留旧路由兼容及所有记录 ID、引用、版本、备份。
2. 使用原 FastAPI 身份认证、资源级授权与审计，实现所有读写和 AI 请求的服务端权限复核。Demo 账号和邀请码仅供本机模拟，绝不能迁入正式身份系统。
3. 以现有后端为统一 DeepSeek 调用服务，密钥仅使用部署环境变量/密钥管理。按 README 列出的 LLM/ASR/TTS/OCR/Search/Fetch 协议逐项验证真实调用、计费与失败处理。对授权资料检索、外部传输同意、来源引用和审计做端到端测试。
4. 迁移结构化学术事件、口述档案与数字资产，使用持久化存储保存原件，机器原稿与人工确认稿分离；建立音频分段与恢复、原件备份、跨设备同步及数据迁移测试。
5. 完成真实账户隔离测试、手机实测、实际字体验收、三维图谱及原有功能回归，才考虑上线。当前不宣称是正式 V3.3 发行版。
