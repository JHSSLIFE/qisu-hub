# 耆宿说 · 设计系统

以 VISUAL_GUIDE.md 与现有已确认界面为品牌基线。本次本地 UI/UX 数据库检索返回了学术研究方向，但通用的蓝金色、拉丁衬线字体和 FAQ 落地页结构不适合中文研究工作台，因此保留现有中国传统色、系统字体和稳定工作空间结构。

## 语义色与排版

| 角色 | 变量/值 | 用途 |
| --- | --- | --- |
| 主操作 | --accent / #425066 黛蓝 | 主按钮、选中导航、标题层级 |
| 页面 | --paper / #fdfdfb | 素白阅读背景 |
| 面板 | --surface / #ffffff | 内容检查区和编辑窗口 |
| 次级面板 | --surface-muted / #f5f7f7 | 筛选、表头、分组 |
| 正文 | --text / #303a42 | 主体阅读 |
| 辅助 | --muted / #65717b | 元数据与辅助说明 |
| 研究关系 | --jade / #4e7169 | 专家与知识线索 |
| 选中/印章 | --rouge / #9d2933 | 三维当前节点、选中构件、印章 |
| 边界 | --border / #e4e8ea | 分隔与面板结构 |

系统宋体用于文化主题标题，系统无衬线用于正文和操作，不加载外部字体。中文长文 16px，辅助文字至少按移动端阅读复核；图谱短标签属于空间导航，仍有检查区、搜索与关系列表作为完整阅读入口。

## 布局与交互

- 桌面：224px 侧栏、顶部检索、留白工作区。列表使用行；研究总览按任务分组。
- 手机：单列主流程、底部五项导航；三维检查区落在场景下方。
- 详情：正文、来源、关联、历史；编辑含来源与关系；Esc 与未保存保护。
- 三维：统一浅色底，知识黛青、专家玉色、资料褐色；当前节点胭脂，直接关系高亮。
- 三维标签使用 DOM 按钮以支持键盘。默认仅为选中及直接相邻节点显示标签，减少遮挡；筛选到小图时显示全部标签。
- 建筑：构件可点击、高亮、拆解、合拢、线框、复位，并链接知识。
- 按需重绘，不自动旋转；GPU 不可用时仍通过 R3F + SVGRenderer 渲染同一套场景。
- 主要按钮保持约 44px 点击区域；hover、focus、pressed、disabled 与空结果均有反馈。

具体实现见 src/theme.css、src/explorer.css。三维教学模型不是历史建筑的真实测绘或复原。
